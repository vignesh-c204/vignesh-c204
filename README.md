## 🚀 Featured Project — StockVision

<div align="center">

<a href="https://github.com/vignesh-c204/StockVision"><img src="https://img.shields.io/badge/📈%20STOCKVISION-EXPLORE%20PROJECT-0d1117?style=for-the-badge&logo=github&logoColor=white" /></a>

</div>

**StockVision** is a Python + Flask web application for stock-market analysis and LSTM-based price prediction. It uses **yfinance** for market data and a trained **TensorFlow/Keras LSTM model** to generate 30-day predictions. fileciteturn48file0

### ✨ Key Features

| Feature | Details |
|---|---|
| 📊 Market Data | Historical stock data through yfinance |
| 🧠 LSTM Model | Sequence-based prediction using TensorFlow/Keras |
| 🔮 Forecast | Date-wise predictions for the next 30 days |
| 🔐 Authentication | Registration, password hashing and sessions |
| 🌐 REST API | Flask `/predict` endpoint |
| 📉 Preprocessing | MinMaxScaler + 60-day input sequences |
| 💾 Model | Saved TensorFlow/Keras model |

### 🧠 ML Workflow

```text
Historical Data → yfinance → Closing Prices → MinMax Scaling
                         ↓
                 Previous 60 Days
                         ↓
                 TensorFlow LSTM
                         ↓
                  Next 30 Days
                         ↓
                Price Predictions
```
